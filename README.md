# ♻️ Plastic Image Classifier

A YOLO11-based computer vision project that detects plastic waste objects from images.

## 📌 Classes

The model detects:

- Bottle
- Bag
- Cup

## 🛠️ Technologies

- Python
- YOLO11
- Ultralytics
- PyTorch
- Streamlit
- OpenCV
- Git & GitHub

## 🚀 Features

- Upload an image
- Detect plastic objects
- Display bounding boxes
- Show confidence scores
- Display prediction summary

## 📊 Model Performance

Validation results:

- Precision: 60.2%
- Recall: 59.2%
- mAP50: 57.6%
- mAP50-95: 43.6%
